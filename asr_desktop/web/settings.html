设置

Qwen3-ASR Desktop 复用 Qwen3-ASR-Service 的 Web UI 与接口形态，语音识别由本机（或局域网）的 Ollama 完成。 修改后点击「保存」，返回主界面刷新即可生效。

Ollama 连接
推荐使用 Ollama ≥ 0.40（支持音频输入的 OpenAI 兼容转写接口）。
本机默认 http://127.0.0.1:11434；局域网可填 http://IP:11434
若尚未下载：ollama pull frozenlab/qwen3-asr:1.7b（0.6b 更快，1.7b 更准）
新版 Ollama 用 OpenAI 兼容接口；若提示 404 可切换为 /api/chat。
主界面未单独选择语言时使用该设置。
实时转写
基于能量检测自动断句，每句送 Ollama 识别；静音越短出字越快。
环境嘈杂可调到 -40，安静环境可用 -50。
运行环境
修改后需重启程序；端口被占用时会自动顺延。
